## 📱 ３. 端末への導入・アプリ化（ホーム画面追加）手順

タブレットやスマートフォンでURLバーや戻るボタンを隠し、専用アプリのように全画面で誤操作なく使用するための設定です。

### 🍎 iPad / iPhone（Safari）の場合
1. Safariブラウザで目的のポータルURLを開きます。
2. 画面上部（または下部）の **共有ボタン**（四角から矢印が飛び出しているアイコン）をタップします。
3. メニューをスクロールし、**「ホーム画面に追加」** を選択します。
4. アイコンの名前を確認（例：「ケアリンク見守り」「ご家族ポータル」）し、右上の「追加」を押します。
5. ホーム画面に専用アイコンが作成され、次回から1タップで全画面起動します。

### 🤖 Android タブレット / スマートフォン（Google Chrome）の場合
1. Chromeブラウザで目的のポータルURLを開きます。
2. 画面右上の **メニューボタン**（縦の3点リーダー「⋮」）をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。
4. ホーム画面にショートカットが追加され、全画面モードで起動できるようになります。

### 🛡️ 居室タブレットのおすすめ設定（キオスク化・誤操作防止）
- **画面自動スリープの解除**: 「設定」➔「ディスプレイ」➔「画面消灯（スリープ）」を「なし」または「常時表示」に設定。
- **アプリ固定（ピン留め）**: Androidの「アプリの固定」機能や、iPadの「アクセスガイド」機能を使用することで、入居者様が誤ってホーム画面に戻ったり設定を変更してしまうのを完全に防ぐことができます。

## ☁️ ４. ご家族ポータル等の外部公開手順（施設管理者向け）

ご家族が自宅や外出先からスマートフォンで閲覧する場合、施設内サーバーを安全に外部中継する **Cloudflare Tunnel（セキュアトンネル）** を使用します。

### トンネル起動コマンド
サーバー端末のプロジェクトルートにて、以下のスクリプトを1回実行するだけで、外部トンネルの発行とGitHub Pagesへの自動反映が完了します。

```bash
cd /media/k3and4/For_AI_Data/Antigravity/TestApp/Nursing_facility
./start_tunnel.sh
```

- **自動中継の仕組み**:
  1. `cloudflared` が起動し、安全な暗号化トンネルURL（`https://xxxx.trycloudflare.com`）を発行。
  2. ご家族向け固定URL（`https://k3and4ai-sudo.github.io/Nursing_facility/`）が最新のトンネルURLを自動検知して接続。
  3. **ご家族様には、サーバー再起動時でも常に変わらない固定URLを一度案内するだけでOKです。**

## ❓ ５. 接続トラブルシューティング

### Q1. 「このサイトにアクセスできません」と表示される
- **原因①**: サーバーPC側でCareLinkシステム（FastAPI / Uvicorn）が起動していない可能性があります。
  - ➔ *管理者にて `python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8000` が起動しているか確認してください。*
- **原因②**: クライアント端末（iPad等）が施設のWi-Fi（同一LAN）に接続されていない可能性があります。
  - ➔ *端末のWi-Fi設定を確認し、施設内の同一ネットワークに接続してください。*
- **原因③**: サーバーのIPアドレスが変わった可能性があります。
  - ➔ *サーバーで `ip a` を実行し、現在のIPアドレスを再確認してください。*

### Q2. 居室端末で「マイクが使用できません」と出る
- **原因**: ブラウザのセキュリティ仕様により、マイク音声の入力は `https://` または `http://localhost` の接続でのみ許可される場合があります。
- **対処法**:
  - 居室タブレットで初回アクセス時に「マイクへのアクセスを許可しますか？」と表示されたら、必ず **「許可」** を選択してください。
  - もしブロックしてしまった場合は、ChromeのURLバー左側の鍵アイコン（または設定アイコン）をタップし、「マイクの権限」を「許可」に変更して再読み込みしてください。

### Q3. ご家族ポータルで「サーバー接続中...」のまま画面が進まない
- **原因**: 施設側のトンネルプログラム（`./start_tunnel.sh`）が停止している可能性があります。
- **対処法**:
  - 施設管理者に連絡し、サーバーでトンネルが稼働しているか確認してください。スタッフステーションの画面右上にある「ご家族トンネル: 稼働中」ランプが緑色になっているか確認することで、稼働状況をチェックできます。
