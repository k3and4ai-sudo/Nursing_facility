# 📚 CareLink 4大ポータル 操作マニュアル集

CareLink（ケアリンク）見守りシステムの4大ユーザーインターフェース（ポータル）に対応した、専用マニュアルの目次です。
利用対象者の年齢や業務内容に合わせ、平易でわかりやすい言葉と注釈付きイラスト・キャプチャ画面を多用して構成されています。
